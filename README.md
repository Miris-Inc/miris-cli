# Miris CLI

Release binaries for the Miris CLI, which lets you work with the Miris platform from your terminal.

**[Download the latest release](https://github.com/Miris-Inc/miris-cli/releases/latest)**, or install with Homebrew:

```sh
brew install miris-inc/tap/miris
```

Installation steps for every platform are in the [Miris documentation](https://docs.miris.com/cli/installation).
